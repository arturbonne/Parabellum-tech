# 🛡️ Parabellum Tech

> **Proteção digital de ponta a ponta.** Transformamos sua presença online em uma fortaleza impenetrável com design excepcional.
> 
> 

A **Parabellum Tech** é um projeto acadêmico de Front-End Web focado na criação de uma agência fictícia que une o melhor de dois mundos: **Engenharia de Usabilidade Segura (UI/UX) e Cibersegurança**. O objetivo do sistema é demonstrar como interfaces visualmente atrativas e focadas em conversão podem coexistir com arquiteturas de proteção rigorosas.

Este repositório guarda todo o código-fonte desenvolvido para a validação da disciplina, construído do zero com foco em semântica, acessibilidade e boas práticas da web.

### 🚀 Funcionalidades e Telas

O projeto conta com mais de 10 páginas interativas, incluindo:

* **Dashboard Interativo:** Painel de controle simples e intuitivo para visualização de métricas.


* **Calculadora de ROI:** Ferramenta dinâmica que calcula e armazena (via LocalStorage) a economia e os ganhos anuais baseados em métricas de tráfego e ticket médio.


* **Planos e Preços:** Tabela comparativa e fluxos de checkout responsivos.


* **Documentações e Mídias:** Central de materiais contendo reprodutores nativos de áudio (Podcast) e vídeo, além de manuais de adequação LGPD, GDPR e OWASP.


* **Suporte:** Central de atendimento 24 horas para mitigação de transtornos.



### 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica rigorosa (uso de `<main>`, `<nav>`, `<section>`, `<header>`, `<footer>`) validada pelo consórcio W3C.


* **CSS3:** Estilização Cyber-Futurista (Deep Navy, Electric Blue e Violeta) construída 100% do zero utilizando Flexbox e CSS Grid Layout para total responsividade.


* **JavaScript (Vanilla):** Manipulação de DOM para interatividade (filtros, alternância de cards) e uso de Web Storage API sem dependência de bibliotecas externas.


* **Figma:** Prototipação de alta fidelidade e planejamento de Experiência do Usuário (UX) e Interface (UI).
